# PyCMT2 STL Reimplementation Design

Design document for aligning PyCMT2's Standard Library (STL) with ECMT2's ModuleLibrary-based approach.

**Date:** 2026-01-07
**Status:** Proposed

---

## Problem Statement

The current PyCMT2 STL implementation has significant architectural differences from ECMT2's STL:

### Current PyCMT2 Approach (Problematic)

1. **Inline SystemVerilog generation**: PyCMT2's `stl.py` generates SystemVerilog RTL strings directly in Python code
   - `_generate_firrtl_reg_rtl()`, `_generate_wire_rtl()`, etc.
   - RTL is stored in `_STL_RTL_REGISTRY` dictionary
   - No connection to the FIRRTL generation pipeline

2. **No ModuleLibrary integration**: PyCMT2 creates external modules ad-hoc without using the shared ModuleLibrary infrastructure
   - ECMT2 uses `ModuleLibrary::loadModule()` with `manifest.yaml`
   - ECMT2 can use Chisel-generated FIRRTL modules
   - PyCMT2 bypasses all of this

3. **FIFO implementation mismatch**:
   - ECMT2's FIFOs (`createFIFO1PushModule`, `createFIFO1PullModule`, `createFIFO2IModule`) are **CMT2 modules** (not external modules)
   - They are built using rules, methods, values, and wire/register instances
   - PyCMT2's FIFOs are external modules with inline SystemVerilog RTL

4. **Memory not implemented**: PyCMT2's `Memory.create()` raises `NotImplementedError`

### ECMT2 Approach (Correct)

From `STLLibrary.cpp`:

| Component | ECMT2 Type | PyCMT2 Type | Issue |
|-----------|-----------|-------------|-------|
| `Reg` | External module (FIRRTL binding) | External module (inline SV) | Wrong RTL source |
| `Wire` | External module (FIRRTL binding) | External module (inline SV) | Wrong RTL source |
| `FIFO1_PUSH` | **CMT2 Module** (built from primitives) | External module (inline SV) | **Wrong abstraction** |
| `FIFO1_PULL` | **CMT2 Module** (built from primitives) | External module (inline SV) | **Wrong abstraction** |
| `FIFO2_I` | **CMT2 Module** (built from primitives) | External module (inline SV) | **Wrong abstraction** |
| `Mem1r1w1c` | External module (FIRRTL binding) | Not implemented | Missing |
| `Mem1r1w0c` | External module (FIRRTL binding) | Not implemented | Missing |

### Key Issues

1. **Architecture inconsistency**: ECMT2 FIFOs use the CMT2 abstraction (rules, methods, wire primitives), while PyCMT2 FIFOs bypass CMT2 entirely with direct RTL

2. **No reuse of ModuleLibrary**: The `manifest.yaml` and Chisel/FIRRTL module generation infrastructure is completely unused

3. **RTL generation in Python**: Violates separation of concerns - RTL should come from ModuleLibrary or be generated by the compiler pipeline

4. **Simulation mismatch**: Because PyCMT2 uses different RTL, simulation results may differ from ECMT2-generated designs

### Phase 1: External Module Alignment

#### 1.1 Remove Inline RTL Generation

Delete the following functions from `stl.py`:
- `_generate_firrtl_reg_rtl()`
- `_generate_wire_rtl()`
- `_generate_fifo1_push_rtl()`
- `_generate_fifo1_pull_rtl()`
- `_generate_fifo2_i_rtl()`
- `_STL_RTL_REGISTRY`
- `get_stl_rtl_files()`
- `add_stl_rtl_to_workspace()`

#### 1.2 Align Reg with ECMT2

**Current (Wrong):**
```python
class Reg:
    @staticmethod
    def create(circuit: Circuit, width: int, init: int = 0):
        name = f"FIRRTLReg_{width}"
        with circuit.external_module(name) as reg:
            reg.clock("clk")
            reg.reset("rst")
            reg.value("read", ready_name="read_ready", ...)
            reg.method("write", enable_name="write_enable", ...)
        _STL_RTL_REGISTRY[name] = _generate_firrtl_reg_rtl(width)  # WRONG
        return circuit._external_modules[name]
```

**Proposed (Correct):**
```python
class Reg:
    @staticmethod
    def create(circuit: Circuit, width: int, init: int = 0):
        # Use parameterized name matching ECMT2
        params = {"width": width, "init": init}
        name = f"FIRRTLReg_{width}_{init}"

        if name in circuit._external_modules:
            return circuit._external_modules[name]

        # Create external module binding (no RTL - comes from ModuleLibrary)
        with circuit.external_module(name) as reg:
            reg.clock("clk", port_name="clock")
            reg.reset("rst", port_name="reset")
            reg.value("read",
                      ready_name="read_ready",
                      returns=[("read_data", UInt(width))])
            reg.method("write",
                       enable_name="write_enable",
                       ready_name="write_ready",
                       args=[("write_data", UInt(width))])
            # Mark as library module for later resolution
            reg.set_library_module("FIRRTLReg", params)

        return circuit._external_modules[name]
```

#### 1.3 Add ModuleLibrary Integration

Add to `Circuit` class:
```python
class Circuit:
    def __init__(self, name: str):
        ...
        self._library_modules: dict[str, dict] = {}  # name -> {lib_name, params}

    def register_library_module(self, ext_mod_name: str, lib_name: str, params: dict):
        """Register an external module as requiring ModuleLibrary resolution."""
        self._library_modules[ext_mod_name] = {
            "library_name": lib_name,
            "params": params
        }

    def get_library_modules(self) -> dict:
        """Get all library modules for emission."""
        return self._library_modules
```

### Phase 2: FIFO Reimplementation as CMT2 Modules

This is the critical change. FIFOs should be **CMT2 modules** built from primitives, not external modules.

#### 2.1 FIFO1Push Implementation

Translate `STLLibrary::createFIFO1PushModule` to Python:

```python
class FIFO1Push:
    @staticmethod
    def create(circuit: Circuit, data_width: int):
        """Create depth-1 push-style FIFO as CMT2 module.

        This matches ECMT2 STLLibrary::createFIFO1PushModule.
        Built from: Reg (data), Reg (full), Wire (deqed), Wire (enqed)
        """
        name = f"FIFO1_PUSH_w{data_width}"

        # Check if already created
        if name in circuit._modules:
            return circuit._modules[name]

        # Create primitive instances
        reg_data_mod = Reg.create(circuit, data_width)
        reg_bool_mod = Reg.create(circuit, 1)
        wire_bool_mod = Wire.create(circuit, 1)

        with circuit.module(name) as fifo:
            clk = fifo.clock("clk")
            rst = fifo.reset("rst")

            # Instances
            reg_data = fifo.instance(reg_data_mod, "reg_data", clk=clk, rst=rst)
            full_reg = fifo.instance(reg_bool_mod, "full_reg", clk=clk, rst=rst)
            deqed = fifo.instance(wire_bool_mod, "deqed", clk=clk, rst=rst)
            enqed = fifo.instance(wire_bool_mod, "enqed", clk=clk, rst=rst)

            # Value: full() -> bool
            with fifo.value("full", returns=[UInt(1)]) as full_val:
                with full_val.guard() as g:
                    g.always()
                with full_val.body() as body:
                    result = body.call(full_reg, "read")
                    body.returns(result)

            # Method: deq() -> data
            # Guard: full_reg.read()
            with fifo.method("deq", returns=[UInt(data_width)]) as deq:
                with deq.guard() as g:
                    is_full = g.call(full_reg, "read")
                    g.returns(is_full)
                with deq.body() as body:
                    body.call(deqed, "write", body.const(1, 1))
                    data = body.call(reg_data, "read")
                    body.returns(data)

            # Method: enq(data)
            # Guard: !full_reg.read() | deqed.read()
            with fifo.method("enq", args=[("data", UInt(data_width))]) as enq:
                with enq.guard() as g:
                    is_full = g.call(full_reg, "read")
                    is_deqed = g.call(deqed, "read")
                    not_full = g.not_(is_full)
                    can_enq = g.or_(not_full, is_deqed)
                    g.returns(can_enq)
                with enq.body() as body:
                    body.call(enqed, "write", body.const(1, 1))
                    body.call(reg_data, "write", body.arg("data"))

            # Rule: deqed_default (write 0 to deqed wire)
            with fifo.rule("deqed_default") as rule:
                with rule.guard() as g:
                    g.always()
                with rule.body() as body:
                    body.call(deqed, "write", body.const(0, 1))

            # Rule: enqed_default (write 0 to enqed wire)
            with fifo.rule("enqed_default") as rule:
                with rule.guard() as g:
                    g.always()
                with rule.body() as body:
                    body.call(enqed, "write", body.const(0, 1))

            # Rule: next (update full_reg)
            # full_reg.write(enqed.read() | (full_reg.read() & !deqed.read()))
            with fifo.rule("next") as rule:
                with rule.guard() as g:
                    g.always()
                with rule.body() as body:
                    is_enqed = body.call(enqed, "read")
                    is_deqed = body.call(deqed, "read")
                    is_full = body.call(full_reg, "read")
                    not_deqed = body.not_(is_deqed)
                    full_and_not_deqed = body.and_(is_full, not_deqed)
                    next_full = body.or_(is_enqed, full_and_not_deqed)
                    body.call(full_reg, "write", next_full)

            # Set scheduling precedence
            fifo.set_precedence([
                ("full", "deq"),
                ("deq", "enq"),
                ("enq", "deqed_default"),
                ("deqed_default", "enqed_default"),
                ("enqed_default", "next")
            ])

        return circuit._modules[name]
```

#### 2.2 WireDefault Implementation

ECMT2 has `createWireDefaultModule` which wraps a Wire with a default value rule:

```python
class WireDefault:
    @staticmethod
    def create(circuit: Circuit, width: int, init: int = 0):
        """Create wire with default value as CMT2 module.

        Matches ECMT2 STLLibrary::createWireDefaultModule.
        """
        name = f"WireDefault_w{width}_i{init}"

        if name in circuit._modules:
            return circuit._modules[name]

        wire_mod = Wire.create(circuit, width)

        with circuit.module(name) as wire_default:
            clk = wire_default.clock("clk")
            rst = wire_default.reset("rst")

            inner = wire_default.instance(wire_mod, "inner", clk=clk, rst=rst)

            # Value: read() -> data (delegates to inner)
            with wire_default.value("read", returns=[UInt(width)]) as read_val:
                with read_val.guard() as g:
                    g.always()
                with read_val.body() as body:
                    result = body.call(inner, "read")
                    body.returns(result)

            # Method: write(data) (delegates to inner)
            with wire_default.method("write", args=[("in_", UInt(width))]) as write_meth:
                with write_meth.guard() as g:
                    g.always()
                with write_meth.body() as body:
                    body.call(inner, "write", body.arg("in_"))

            # Rule: default (writes init value)
            with wire_default.rule("default") as rule:
                with rule.guard() as g:
                    g.always()
                with rule.body() as body:
                    body.call(inner, "write", body.const(init, width))

            # Precedence: write < default < read
            wire_default.set_precedence([
                ("write", "default"),
                ("default", "read")
            ])

        return circuit._modules[name]
```

### Phase 3: Memory Implementation

Implement Memory modules using ModuleLibrary bindings:

```python
class Memory:
    @staticmethod
    def create_1r1w_sync(circuit: Circuit, data_width: int, addr_width: int, depth: int):
        """Create 1R1W synchronous memory (1-cycle read latency).

        Matches ECMT2 STLLibrary::createMem1r1w1cModule.
        """
        name = f"Mem1r1w1c_w{data_width}_a{addr_width}_d{depth}"
        params = {"data_width": data_width, "addr_width": addr_width, "depth": depth}

        if name in circuit._external_modules:
            return circuit._external_modules[name]

        with circuit.external_module(name) as mem:
            mem.clock("clk", port_name="clock")
            mem.reset("rst", port_name="reset")

            # rd0: initiate read (no output this cycle)
            mem.method("rd0",
                       enable_name="en",
                       args=[("raddr", UInt(addr_width))])

            # rd1: read result available (value, not method)
            mem.value("rd1",
                      ready_name="rd1_valid",
                      returns=[("rdata", UInt(data_width))])

            # write: write data
            mem.method("write",
                       enable_name="wen",
                       args=[("wdata", UInt(data_width)),
                             ("waddr", UInt(addr_width))])

            mem.set_library_module("Mem1r1w1c", params)

        return circuit._external_modules[name]

    @staticmethod
    def create_1r1w_async(circuit: Circuit, data_width: int, addr_width: int, depth: int):
        """Create 1R1W asynchronous memory (0-cycle read latency).

        Matches ECMT2 STLLibrary::createMem1r1w0cModule.
        """
        name = f"Mem1r1w0c_w{data_width}_a{addr_width}_d{depth}"
        params = {"data_width": data_width, "addr_width": addr_width, "depth": depth}

        if name in circuit._external_modules:
            return circuit._external_modules[name]

        with circuit.external_module(name) as mem:
            mem.clock("clk", port_name="clock")
            mem.reset("rst", port_name="reset")

            # read: combinational read
            mem.method("read",
                       enable_name="en",
                       args=[("raddr", UInt(addr_width))],
                       returns=[("rdata", UInt(data_width))])

            # write: write data
            mem.method("write",
                       enable_name="wen",
                       args=[("wdata", UInt(data_width)),
                             ("waddr", UInt(addr_width))])

            mem.set_library_module("Mem1r1w0c", params)

        return circuit._external_modules[name]
```

## API Changes

### Breaking Changes

1. **FIFO classes return CMT2 modules, not external modules**
   - Old: `FIFO1Push.create()` returns `ExternalModuleBuilder`
   - New: `FIFO1Push.create()` returns `ModuleBuilder`

2. **Removed functions**:
   - `get_stl_rtl_files()` - No longer needed
   - `add_stl_rtl_to_workspace()` - No longer needed
   - `clear_stl_registry()` - No longer needed

3. **Memory API**:
   - Old: `Memory.create()` raises `NotImplementedError`
   - New: `Memory.create_1r1w_sync()` and `Memory.create_1r1w_async()`

### Migration Guide

```python
# Old code (will break):
from pycmt2.stl import FIFO1Push, get_stl_rtl_files

fifo_mod = FIFO1Push.create(circuit, 32)  # Returns ExternalModuleBuilder
fifo = m.instance(fifo_mod, "fifo", clk=clk, rst=rst)

# In simulation setup:
add_stl_rtl_to_workspace(workspace)  # REMOVED

# New code:
from pycmt2.stl import FIFO1Push

fifo_mod = FIFO1Push.create(circuit, 32)  # Returns ModuleBuilder (CMT2 module)
fifo = m.instance(fifo_mod, "fifo")  # No clk/rst needed (internal)

# No RTL injection needed - all handled by compiler pipeline
```

## Appendix: ECMT2 FIFO1Push Structure

From `STLLibrary.cpp:createFIFO1PushModule`:

```cpp
Module* STLLibrary::createFIFO1PushModule(unsigned dataWidth, Circuit& circuit) {
  auto *fifoMod = circuit.addModule(moduleName);
  fifoMod->setPrecedence({
      {"full", "deq"},
      {"deq", "enq"},
      {"enq", "deqed_default"},
      {"deqed_default", "enqed_default"},
      {"enqed_default", "next"}
    });

  // Instances
  auto *reg = fifoMod->addInstance("reg_data", regDataT, {clk, rst});
  auto *fullReg = fifoMod->addInstance("full_reg", regBooleanT, {clk, rst});
  auto *deqed = fifoMod->addInstance("deqed", wireBooleanT, {clk, rst});
  auto *enqed = fifoMod->addInstance("enqed", wireBooleanT, {clk, rst});

  // Value: full() -> bool
  // Method: deq() -> data  [guard: full_reg.read()]
  // Method: enq(data)      [guard: !full | deqed]
  // Rule: deqed_default    [write 0 to deqed]
  // Rule: enqed_default    [write 0 to enqed]
  // Rule: next             [full = enqed | (full & !deqed)]
}
```

Key observations:
- Uses **4 instances**: reg_data, full_reg, deqed (wire), enqed (wire)
- Has **3 interface members**: full (value), deq (method), enq (method)
- Has **3 internal rules**: deqed_default, enqed_default, next
- Precedence chain ensures correct scheduling order
